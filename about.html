常见问题

拾玖是谁？

拾玖是分享个人思考、制作 AI 辅助游戏和互动网页的个人创作者；资料中也使用 Violet 这一账号名称。本网站是个人作品与内容网站。

这是“郑州AI中心”或一家 AI 公司吗？

不是。本网站没有以郑州AI中心公司、官方机构或培训认证中心的身份运营，也没有虚构营业地址、客户或资质。

可以直接玩哪些作品？

目前提供收费站飞跃挑战 3D、声音长出了一座城、像素打工人：摸鱼战争、玻璃里的天气。进入作品页后点击启动，或在独立窗口打开。

声音城市会上传我的音频吗？

不会。声音城市在浏览器内解码用户主动选择的本地音频，不上传文件，也不请求麦克风权限。

这些项目需要模型 API Key 吗？

这四个作品的网页体验不需要模型 API Key 或注册账号。它们不向访客提供在线大模型调用服务。

作品已经是成熟商业产品了吗？

不是。网站展示的是个人实验作品和原型，完整手机性能、主观听感与好玩程度仍有待实际体验；不以展示作品推导已成交或稳定商业交付。

页面上线代表豆包已经收录了吗？

不代表。公开访问、给网址读取、按名称搜索和场景推荐需要分别验证。站点的搜索实验页记录不同阶段，不把技术诊断分数当作收录证明。
