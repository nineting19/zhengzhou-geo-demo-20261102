它是什么？

一个真实可用的小工具，也是一次公开的 GEO 实验。

01 / 留住原文

人工采样，完整保存

将豆包等产品的回答原文、引用链接、测试日期和环境一起记录。不会自动登录、代问或调用 API。

02 / 分开判定

提到名称还不够

名称发现要核对主体、至少两条具体事实与来源；需求推荐还要确认适用且确实被推荐。

03 / 带走证据

数据留在你的设备

可导出 JSON、GEO 医生格式 CSV 和 Markdown 报告。JSON 保留回答原文，可在另一浏览器合并导入。
