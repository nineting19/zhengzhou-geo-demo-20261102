LOCAL FIRST

记录保存在当前浏览器。

本应用的采样原文、复核标记和来源链接保存到此站点当前浏览器的 localStorage。应用代码没有上传采样内容的接口，没有接入分析统计或付费模型 API。导出由本机浏览器生成文件。

访问在线页面时，托管服务仍会处理提供网页所必需的网络请求；本地保存不等于完全没有网络请求。离线单文件版下载后无需联网即可记录与导出。点击外部来源会访问对应站点。

使用条件

现代浏览器，启用 JavaScript。在线版需要能访问本域名；无需注册本工具账号或填写 API Key。你使用豆包等平台时，其登录和使用条件由对应平台决定。当前工具免费，不承诺无限期托管。

保留和交换

数据不会自动跨设备同步。清理站点数据、隐私模式结束或浏览器空间不足可能造成数据不可用。每轮采样后请导出 JSON；CSV 和 Markdown 是交换及展示格式，JSON 才是完整回导文件。

导入最多 3 MB、2000 条记录，按 id 去重，不覆盖已有记录。模拟数据与真实采样分区。记录可能包含个人信息，分享前自行核对内容；本站没有自动脱敏功能。

离线版注意事项

离线文件的 localStorage 支持依浏览器而异，移动文件也可能导致历史记录无法访问。以 JSON 导出为持久备份。离线文件中的来源链接和操作指南链接仍需要联网。
