上游项目是方鑫三个金 / Fangx-AI 的 GEO 医生（geo-doctor）。本站使用本地检出的 1.8.0 版本，提交 a2c239a39a501efc3ba118389694c30d88d4b9e4。源码中的命令与模板是依据；公众号讨论帮助理解目标，无法访问的历史文章不作为已审阅材料。

哪些是本次新增？

拾玖搜证台的页面设计、本地记录器、判定汇总、JSON 合并导入与离线导出是本次新实现。GEO 医生工作台、生成器、草稿检查与发布包来自上游，不宣称为本项目原创。

目前为什么先做网页？

这个 demo 的对象是一个真实小工具，网页同时能展示事实、让人直接试用并提供来源链接。先验证能否匿名访问与准确读取，再观察独立发现。自媒体账号是后续可选的外部来源，不是“开账号就被搜到”的捷径。

站点现部署在 GitHub Pages。此前 Sites 地址在实际检查和用户手机中遭遇 Cloudflare 拦截，因此迁移到独立子目录。托管平台变更本身不是豆包独立发现成功的证据。若后续补平台文章，要真实披露作者与项目关系，保留公开链接和发布时间。

目前完成度与边界

产品功能、事实表达、公开部署、独立发现是不同层级。本站不提供自动代问、登录绕过、自动排名或效果保证。不把模拟练习当真实采样，不把 API 回答当 App 搜索，不把两个不同网址的读取差异当同一页面更新效果。
